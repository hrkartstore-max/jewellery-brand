# AURELIA — Premium Jewellery E-commerce

Production-ready Next.js 15 App Router storefront with responsive luxury editorial UI, reusable product components, INR pricing, SEO-friendly routes, accessibility foundations, and Vercel-ready configuration.

## Deployment

The main branch is the production source. The latest production fixes include the corrected Next.js error boundary and ESLint ESM configuration.

## Routes

/, /shop, /collections/[slug], /products/[slug], /about, /contact, /journal, /size-guide, /jewellery-care, /faq, /cart, /wishlist, /account, /search

## Run

npm install
npm run build
npm run dev
